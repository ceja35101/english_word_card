# えいご絵カード

## Web公開

`npm run build-site` で公開用ファイルを `dist/` にまとめます。元のHEIC写真や開発用データは公開用フォルダーに含めません。
GitHub Pagesの公開元を「GitHub Actions」に設定すると、`main` へのプッシュで `.github/workflows/pages.yml` が自動公開します。
Web版の履歴は公開URLのブラウザー内に保存されます。ローカルファイル版の履歴は自動では移行されません。

`index.html` をダブルクリックするとブラウザーで起動します。カードの表示・学習にインターネット接続やインストールは不要です。読み上げは端末・ブラウザーの英語音声を利用し、音声によっては接続が必要です。

## 読み上げ・例文

抽象的な単語は、絵の代わりに日本語の意味を表示します。頻度・時間・数や順番・位置関係・教科・気持ちや性質・抽象的な動詞などが対象です。対応表は `japanese-prompts.cjs` で管理し、`npm run build-cards` でカードへ反映します。答え合わせ後には英単語と例文を表示し、従来どおり読み上げ・復習・履歴保存を利用できます。

全710語に短い英語の例文を用意しました。答え合わせ、または「英単語を表示する」の後に例文が表示されます。「単語を聞く」「例文を聞く」で読み上げ、「速さ」で3段階の速度を選べます。「停止」やカードの移動で読み上げを止めます。

読み上げにはブラウザーの [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) を使います。利用できる音声は端末とブラウザーによって異なり、端末内の英語音声を優先します。対応しないブラウザーや英語音声が見つからない場合は、ボタンを無効にして案内を表示します。APIキーは不要です。

例文は `make-examples.cjs` で生成し、`data/examples.json` と各カードの `example` に保存します。`npm run build-cards` で再生成できます。

## 開発言語と構成

HTML・CSS・JavaScriptで構成した静的Webアプリです。アプリはブラウザー内で動作します。

| 言語・形式 | 主なファイル | 役割 |
| --- | --- | --- |
| HTML | `index.html`, `credits.html` | 画面の構造 |
| CSS | `style.css`, `library.css`, `learning.css`, `speech.css` | デザイン・スマートフォン対応 |
| JavaScript | `app.js`, `learning.js`, `speech.js`, `cards.js` | 画面操作・採点・復習・履歴保存・読み上げ・カード情報 |
| JavaScript（Node.jsで実行） | `*.cjs` | 教材生成・画像処理・ダウンロード・テストなどの開発作業 |
| JSON（データ形式） | `data/*.json` | 単語・例文・画像出典などのデータ |
| SVG（画像形式） | 教材の図 | 図形・教材画像 |

Node.jsはJavaScriptを実行する環境です。通常のアプリ利用時に起動する必要はありません。履歴はブラウザーの `localStorage` に保存します。

1. 必要に応じて「学習するカテゴリー」で範囲を選びます。
2. 絵から英単語を考えます。
3. 入力フォームに英単語を入力し、「答え合わせ」（または Enter）で正誤を確認します。
4. 「次のカード」で進みます。番号選択、シャッフルも利用できます。カード移動時は答えが自動で隠れます。

添付一覧の全710語を元の通し番号で登録しています。711〜791番の空欄は除外しています。綴りの補正は `data/spelling-corrections.json` に記録し、画面では答えの表示後に補正内容を確認できます。元の一覧は `data/words-original.txt` です。

## 正誤判定・復習・履歴

- 大文字・小文字、全角・半角、前後と連続する空白は区別しません。綴りは一致が必要です。`Autumn/Fall` は `Autumn`、`Fall` のどちらでも正解です。
- 間違えた問題は、最後に間違えた日を基準として **1・3・7・28日後** に優先出題します。日付は日本時間です。たとえば10月10日に間違えると、10月11日・13日・17日・11月7日が復習日です。
- 復習で正解しても、残りの復習予定は残ります。再び間違えると、その日を基準に4回の予定を作り直します。
- 期限を過ぎた問題も起動時に優先します。複数の復習日を過ぎていた場合、1回の正解で期限到来済みの回をまとめて完了し、将来の予定を残します。
- カテゴリーを選択しても、その範囲の復習問題が先に出ます。シャッフルでも復習問題を先に出します。「復習から始める」は全カテゴリーの復習問題から始めます。
- 出題した日時・問題・入力した答え・正誤をブラウザーの `localStorage` に保存します。「学習履歴」で過去の出題を確認でき、「さらに50件表示」で古い記録も見られます。未回答や、答えだけを確認した記録も残ります。
- 「英単語を表示する」で先に答えを見た場合は、その出題の採点を行わず、復習予定も完了にしません。
- 履歴は同じブラウザー・同じ端末・同じ保存先で引き継がれます。ブラウザーのデータ削除で消えるため、「全履歴をJSONで保存」から書き出せます。保存できない環境や保存領域の不足は画面に表示します。

写真22枚を回転補正し、右側の絵（小さな絵は上部の絵）と左側の英単語を別々のJPEGに切り出しました。答えには読みやすい文字を表示し、「写真の英単語を見る」で切り出した単語も確認できます。元のHEIC写真は変更していません。

現在は元写真から切り出した絵をすべて教材画像へ差し替えています。番号1・2・6・7・8・11・13・15・16・19・20・22には ARASAAC の画像を、先に差し替えた10語には生成イラストを表示します。写真の英単語は、答えを確認するときだけ任意で開けます。

画像: `assets/cards`（写真）、`assets/pictograms`（公開教材画像）、`assets/illustrations`（生成画像）、`assets/diagrams`（図） / カードデータ: `cards.js`

番号3・4・5・9・10・12・14・17・18・21の絵は、単語の意味がわかりやすい教材用イラストに差し替えています。画像は `assets/illustrations`、割り当ては `image-overrides.json`、生成プロンプトは `assets/illustrations/prompts.json` に保存しています。画像の再変換後もこの割り当てを維持します。

追加分は主に ARASAAC の教材画像を利用し、対応する画像のないものだけ生成しています。数・順番・色・形・曜日・月・位置・頻度などは、英語の答えが写らない図を作成しています。画像はすべてローカルに保存してあるため、学習中の外部画像取得はありません。

画像の出典と利用条件はアプリ下部の「画像の出典」および `IMAGE-CREDITS.md` に記載しています。ARASAAC の画像と、その画像を組み込んだ図には CC BY-NC-SA（非商用・継承）が適用されます。

開発・再構築には Node.js を使用します。

- `npm install`：開発用の依存関係をインストールします。
- `npm run build-cards`：保存済みの一覧・カタログ・画像割り当てから710語のデータと図を再構築します。
- `npm run prepare-images`：元写真の変換と切り出しを実行し、710語の単語帳を再構築します。
- `npm run download-images`：必要な ARASAAC 画像を取得します（ネット接続が必要）。
- `npm run review-images`：画像の一覧プレビューを `review/` に出力します。
- `npm test`：Edge で全710語の画像読み込み、カテゴリー、答えの表示、シャッフル、スマートフォン幅などを確認します。開発環境に Edge が必要です。
